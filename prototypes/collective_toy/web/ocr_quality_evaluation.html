Evaluación reproducible de OCR para el Juguete Colectivo

Esta página ejecuta Tesseract.js real en el navegador sobre imágenes sintéticas generadas localmente. No mide detección de flechas ni valida grafos. La primera ejecución necesita conexión para cargar Tesseract.js y los datos lingüísticos desde CDN.

Privacidad: las imágenes de prueba se generan en esta página y se procesan en el navegador; no se suben a un servicio OCR. Esta página no demuestra funcionamiento sin conexión.

Configuración inicial: Tesseract.js 5, idiomas spa+eng, fuente sans-serif oscura sobre fondo blanco, fixtures 1200 × 360. Los resultados dependen de navegador, plataforma y versión real de los recursos cargados; conserva el JSON para reproducibilidad.
