### Python patch-policy limitation

Python 3.12.10 was selected because it is the last Python 3.12 release with binary installers. Python 3.12.16, released on 2026-10-25, is a later security-only source release and does not provide binary installers. Therefore the workflows have an exact, installable CPython 3.12 runtime, but it is not the latest 3.12 security-patched source version.

This limitation is explicit and must not be hidden by the runtime manifest. Before the first authorized execution, the project must either accept this bounded runtime limitation or separately approve a move to a newer binary-supported Python minor and re-resolve/re-hash all profile wheels. No such migration is made here.
