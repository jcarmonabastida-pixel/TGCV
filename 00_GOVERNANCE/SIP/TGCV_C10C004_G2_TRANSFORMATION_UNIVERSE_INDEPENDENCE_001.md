# C10C-004 — G2 Transformation-Universe Independence

Status: PASS — BOUNDED PRE-SPECIFICATION

G2 establishes that the candidate transformation universe can be defined from the baseline instrument and TGCV operational logic before inspecting treatment/control endline differences or downstream outcomes.

Frozen transformation classes:
- independent economic activity
- productive activity configuration
- input/material acquisition and use
- production/processing configuration
- market/trade activity
- decision and control configuration
- mobility/autonomy enabling configuration
- training/skill-related capability configuration

Primary baseline capability/agency representation: j1_*–j13. These variables are state/capability information, not transformations themselves. Baseline resource and constraint variables may enter the admissibility predicate only when required to determine feasibility.

Independence rule: transformation classes must be definable without treatment assignment, endline treatment differences, downstream outcomes, value measures, post-hoc significance, or realised post-treatment trajectories.

State-versus-transformation rule: a change in an observed variable is not Delta T_acc by itself. Delta T_acc requires an explicit mapping from state conditions to admissible transformations.

Excluded from universe definition: treatment-induced client/admin variables, outcome-selected variables, value metrics, and post-hoc transformations.

Interpretation boundary: G2 does not establish accessibility, Delta T_acc, treatment effects on accessibility, mediation, trajectory effects, or value creation.

Governance effect: Core unchanged; RMA unchanged; evidence-to-claim matrix unchanged; no claim-level upgrade.
