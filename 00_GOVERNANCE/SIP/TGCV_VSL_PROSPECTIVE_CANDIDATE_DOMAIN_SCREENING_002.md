# TGCV — VSL Prospective Candidate Domain Screening 002

**Date:** 2026-09-19  
**Status:** CLOSED — PROSPECTIVE SCREENING; NO CANDIDATE SELECTED  
**Protocol basis:** VSL-SPEC-01 v0.1 FROZEN; VSL-EXP-01 v0.1 FROZEN; TGCV_VSL_PROSPECTIVE_DOMAIN_BOUNDED_VALUATION_SPECIFICATION_DESIGN_001

## 1. Purpose

Screen external domain families for a prospective Value study using the new domain-bounded valuation design gate. The purpose is to identify domains where Value can be declared prospectively, independently of observed TGCV outcomes.

This is a screening exercise, not a compatibility assessment and not a domain selection.

## 2. Exclusion boundary

CD-01 through CD-05 are excluded from this screening as already blocked under the frozen VSL route. No retrospective reopening is authorized.

## 3. Candidate A — Built assets / infrastructure life-cycle costing

Reference standard: ISO 15686-5:2017, Buildings and constructed assets — Service life planning — Part 5: Life-cycle costing.

The standard provides requirements and guidance for life-cycle cost analyses of buildings and constructed assets. It explicitly defines relevant costs/cash flows over an agreed analysis period and describes comparison between alternatives or estimation of future costs.

Screening relevance:
- domain is externally defined;
- evaluative unit can be an asset, component, project or portfolio;
- time horizon is explicitly part of the method;
- costs/cash flows can be operationalized before observing TGCV results;
- alternative/reference definitions can in principle be frozen prospectively.

Open issues:
- whether LCC should be treated as Value itself or as Outcome evidence from which a separate Value mapping is constructed;
- evaluative perspective and decision objective must be explicitly declared;
- aggregation, externalities, uncertainty and counterfactual rules require domain-specific freezing;
- TGCV compatibility has not been tested.

Preliminary disposition: PROSPECTIVE-CANDIDATE — REQUIRES V01-V12 SPECIFICATION.

## 4. Candidate B — Petroleum/petrochemical/natural-gas life-cycle costing

Reference standard: ISO 15663:2021.

The standard specifies requirements and guidance for applying life-cycle costing to create value in development and operations in petroleum, petrochemical and natural-gas contexts. It addresses decisions between competing options differentiated by cost and/or economic value and includes life-cycle decision support.

Screening relevance:
- explicit domain-bounded economic evaluation context;
- explicit competing-option structure;
- life-cycle horizon;
- cost/economic-value decision variables;
- prospectively specifiable decision context.

Open issues:
- the phrase create value in the standard does not by itself establish TGCV Value identification;
- the substantive evaluative objective, perspective and exact Outcome-to-Value mapping still require independent declaration;
- the domain is highly specialized and may introduce additional confounding operational constraints;
- TGCV compatibility has not been tested.

Preliminary disposition: PROSPECTIVE-CANDIDATE — REQUIRES V01-V12 SPECIFICATION.

## 5. Candidate C — Systems/software product quality

Reference standard: ISO/IEC 25010:2023.

The standard defines a product quality model for ICT and software products with characteristics and subcharacteristics intended for specification, measurement and evaluation throughout the product lifecycle.

Screening relevance:
- explicit quality constructs;
- explicit measurement/evaluation architecture;
- lifecycle applicability;
- potentially compatible with prospective Outcome declaration.

Critical methodological limitation at screening stage:
The standard defines quality characteristics, not a complete TGCV Value construct. Therefore it cannot be treated as Value merely because quality is measured or evaluated.

Preliminary disposition: SECONDARY-CANDIDATE — REQUIRES AN EXPLICIT PROSPECTIVE VALUE OBJECTIVE BEFORE COMPATIBILITY TESTING.

## 6. Screening rule

No candidate is selected because it appears economically attractive, has a known standard, or contains the word value.

A candidate advances only if a domain-specific specification can independently freeze:
- unit;
- evaluative perspective;
- Outcome;
- reference/counterfactual;
- evaluative objective;
- O → V* mapping;
- directionality;
- horizon;
- trade-offs;
- aggregation;
- uncertainty/missingness;
- identification status.
