## 1. Purpose and status

This register records the first bounded WP2 search pass. Candidates are **opportunity hypotheses**, not scientific evidence for TGCV.

The classifications below are provisional screening classifications derived from public descriptions. They identify cases worth deeper WP2 analysis; they do not establish that TGCV fits, that cross-domain coupling is causal, or that TGCV provides differential value.

## 2. Candidate set

### WP2-C01 — Multi-domain 5G zero-touch orchestration / ACROSS

**Context:** 5G/beyond-5G network orchestration, cloud-edge environments, security and network digital twins.

**Observed problem structure:** The European Commission's CORDIS reporting for ACROSS describes an AI-driven multi-domain orchestration platform integrating zero-touch provisioning, heterogeneous cloud-edge environments, deep telemetry, security mechanisms, DDoS detection and a Network Digital Twin. citeturn0search13

**Provisional WP2 classification:**
- Domain: network + cloud/edge + security + AI
- Coupling: D3 — coupled transformation spaces (provisional)
- Hibridación candidates: capability propagation; cross-domain dependency; cascading reconfiguration; constraint propagation
- Mechanism candidates: opening/closing options; creating/removing capabilities; changing constraints determining `Pτ`
- Maturation question: applicability / deployment, with possible later scientific question
- Candidate next proof: bounded synthetic cross-domain transformation mapper

**Why retained:** The public description explicitly concerns coordinated transformations across heterogeneous technical domains. This makes it a strong structural candidate for testing the multidomain hypothesis, subject to reconstructing concrete state, candidate transformations and admissibility conditions.

**Non-claim:** No evidence yet that TGCV adds differential value beyond existing orchestration architectures.

## 3. Preliminary WP2 observation

The initial search already identifies several candidate classes in which the **problem itself is structurally cross-domain**, rather than merely occurring in a sector with multiple technologies.

Particularly clear examples include:

- 5G/cloud-edge/security orchestration;
- cybersecurity/network/AI-agent operations;
- energy/mobility resource and constraint coupling;
- social/administrative service trajectories;
- healthcare/social-care integration;
- cross-agency public-service workflows.

This is a useful signal for continuing WP2, but it is **not yet evidence of differential TGCV value**.

## 4. Immediate next WP2 action

The next pass should not expand the candidate list indiscriminately. It should deepen a smaller set of structurally distinct candidates and attempt to reconstruct, at least conceptually:

`S_t → candidate transformations → accessibility/admissibility → T_acc,t → intervention/transition → T_acc,t+1 → coupled downstream trajectory`

The deepening should test whether the apparent multidomain coupling survives this reconstruction or collapses into ordinary coordination/context.
