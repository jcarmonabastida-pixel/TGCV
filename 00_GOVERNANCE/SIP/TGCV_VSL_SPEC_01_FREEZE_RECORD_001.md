## 3. Frozen methodological boundary

VSL-SPEC-01 defines requirements for identifying Value in a future domain-specific VSL.

It does not define a universal substantive Value construct.

The following distinctions are frozen:

`Outcome != Value`

and:

`Outcome -> domain-specific Value`

under a pre-specified evaluative mapping.

## 4. Frozen independence boundary

A domain-specific VSL governed by VSL-SPEC-01 must not derive its semantic identity retrospectively from:

- `T_acc`;
- `Delta T_acc`;
- transformation identity;
- selected transformation;
- treatment assignment;
- accessibility-change status;
- expected-result labels;
- Value-derived variables.

Causal relations between these variables and Value are not assumed by VSL-SPEC-01.

## 5. Frozen domain-selection rule

VSL-SPEC-01 must precede selection of the candidate domain for the corresponding VSL experiment.

A candidate domain that cannot satisfy the essential identification requirements may be classified:

`VALUE_NOT_IDENTIFIED`

or, where justified:

`VALUE_PARTIALLY_IDENTIFIED`

The specification must not be weakened retrospectively to accommodate a candidate domain.
