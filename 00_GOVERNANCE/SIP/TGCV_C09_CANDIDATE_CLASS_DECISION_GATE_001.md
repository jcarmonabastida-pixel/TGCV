# TGCV — C09 Candidate-Class Decision Gate 001

**Status:** `COMPLETED — RETROSPECTIVE BATCH CLOSED / NEW EXECUTION NOT AUTHORIZED`
**Date:** 2026-09-13
**Claim:** C09 — Accessibility changes causally affect subsequent trajectories
**Parent:** `TGCV_C09_RETROSPECTIVE_TR132_REVIEW_RECONCILIATION_001.md`
**Execution authorization:** `NONE`

## 1. Purpose

Decide whether C09 should continue through another search for conventional external RCTs or move to a purpose-designed controlled domain.

This gate is applied after the retrospective batch and incorporates the fact that TGCV already has substantive evidence from SWIM and FOS concerning accessibility/trajectory structure. The purpose is therefore not to restart C09 evidence gathering from zero, but to identify the smallest remaining evidential gap.

## 2. Existing evidence boundary

The current programme already contains bounded evidence relevant to:

- accessibility-space representation and changes in accessible transformations;
- observed/reconstructible linkage between accessibility conditions and subsequent trajectories;
- structural empirical evidence distinguishing accessibility change from downstream reach/trajectory quantities.

These bodies of evidence do **not** by themselves establish the stronger causal claim. In particular, association or reconstruction cannot be promoted to causality without an ex-ante intervention/counterfactual design.

## 3. Retrospective candidate-class result

The completed candidate batch did not identify a conventional external study satisfying simultaneously:

`independent accessibility intervention + defensible counterfactual + bounded TR-132 representation + unit-level reproducibility + direct-effect exclusion`.

The dominant blocker is therefore methodological fit, not absence of randomized studies or absence of longitudinal outcomes.

## 4. Decision criteria

### Route A — continue external conventional-RCT search

Allowed only if a candidate class can provide, from an admissible public package:

1. explicit ex-ante accessibility rule;
2. unit-level `T_acc,0` and `T_acc,1` reconstruction;
3. intervention changing accessibility without encoding the target trajectory;
4. defensible treatment/control or counterfactual identification;
5. independently reconstructible fixed-horizon trajectory;
6. direct-effect exclusion;
7. reproducible provenance and hashing.

A generic RCT, lottery, subsidy, treatment assignment or rich outcome dataset is insufficient.

### Route B — controlled TGCV-designed domain

Preferred if no external candidate class can satisfy Route A without restricted data, unavailable infrastructure, post-treatment reconstruction, or conceptual substitution of treatment/outcome for accessibility.

The controlled domain must be designed so that:

`Z → T_acc,1/T_acc,0 → trajectory`

is explicitly manipulable and independently observable while the trajectory mechanism, objective/scoring rule and observation procedure remain invariant.

## 5. Gate result

**DECISION: ROUTE B — CONTROLLED TGCV-DESIGNED DOMAIN IS THE PREFERRED NEXT STAGE.**

The retrospective candidate search is closed for now. No additional conventional RCT should be searched merely to accumulate another randomized intervention with outcomes.

This is not a C09 claim confirmation. It is a research-design decision based on repeated operational failure of the external candidate class against the same TGCV-specific admissibility condition.

## 6. Scientific status of C09

`C09 = OPEN — CAUSAL EXECUTION GAP REMAINS`

The existing SWIM/FOS/RUST-DYN-2 evidence should be retained as bounded supporting evidence and should not be discarded or duplicated. The unresolved step is a controlled causal demonstration of an exogenous accessibility change producing a distinguishable subsequent trajectory under a frozen counterfactual design.

No claim upgrade is authorized.

## 7. Next operation

Design the **C09 controlled TGCV domain pre-execution package**. It must instantiate a minimal synthetic/controlled transformation system in which accessibility can be intervened upon independently of the trajectory-generating mechanism, with frozen state/context, candidate universe, accessibility rule, treatment assignment, trajectory horizon, estimand, falsification criteria, and reconstruction hashes.

Execution remains unauthorized until the pre-execution package passes its design audit.
