# TGCV — C09 Non-Redundancy Audit 001

**Status:** `CLOSED — CAUSAL GAP CONFIRMED / NO REDUNDANT EMPIRICAL RERUN`
**Date:** 2026-09-13
**Claim:** C09 — Accessibility changes causally affect subsequent trajectories

## 1. Purpose

Determine whether the current C09 work duplicates an already closed FOS/SWIM result, and isolate the smallest genuinely unresolved scientific question.

## 2. Audited evidence sequence

The closed SWIM Reactive-0 operationalization already established, within its bounded exemplar, the reconstructable sequence:

`candidate identity → pre-outcome accessibility Pτ(S_t,C_t) → T_acc,t → ΔT_acc → native selection → execution → outcome`

It reconstructed multiple `T_acc` snapshots and non-empty `ΔT_acc` transitions independently of downstream outcome. The subsequent trajectory-linkage reconstruction further established:

`S_t,C_t → Pτ(S_t,C_t) → T_acc,t → ΔT_acc,t → selected τ_t → S_{t+1},C_{t+1} → bounded subsequent trajectory`

with a closed disposition of **bounded observed association / reconstructability**, explicitly excluding causal inference. Therefore the empirical linkage needed for C08 has already been addressed in the bounded FOS/SWIM surface.

## 3. What FOS/SWIM does NOT establish

The existing evidence does not identify a counterfactual causal contrast of the form:

`do(accessibility = 1) vs do(accessibility = 0) → different subsequent trajectory`

under otherwise equivalent decision-time conditions.

In particular, the observed `ΔT_acc` in Reactive-0 is generated by ordinary state evolution within the executed system. The reconstruction observes what followed an accessibility change; it does not establish what would have happened under the alternative accessibility condition at the same decision point.

Consequently, repeating Reactive-0, adding more observations of the same linkage, or rerunning RUST-DYN-2 would not by itself close C09.

## 4. Prior C09 discovery/operationalization already completed

The prior discovery chain has already narrowed the causal problem substantially:

- D-OPS-19 established the requirement for an independently governed rule layer, finite `U_tau`, non-circular `P_tau` and longitudinal state identity, and rejected repeated unconstrained domain churn.
- D-OPS-20 screened causal intervention domains and closed with no newly admitted candidate.
- D-OPS-22 identified randomized demand-response access interventions as the strongest current C09 candidate class and explicitly identified the remaining bottleneck: formalizing the intervention as a change in `T_acc` rather than merely an incentive/behaviour treatment.
- D-OPS-23 then bounded the Southwestern-China 2019 EDR candidate and left only `U_tau`, `P_tau`, the exact `Z → ΔT_acc` mapping and provenance/reconstruction open.

Thus the current C09 candidate is not a new domain search. It is a targeted causal-identification problem on an already screened candidate.

## 5. Mapping to the current C09 design

The new C09 causal design specification correctly adds the missing causal layer:

`exogenous accessibility intervention → ΔT_acc → subsequent trajectory`

Its required additions over FOS/SWIM are:

1. exogenous treatment assignment or equivalent identification;
2. a credible control/counterfactual condition;
3. verification that treatment actually changes `T_acc`;
4. an intervention that does not directly encode the trajectory outcome;
5. a trajectory outcome fixed before inspection;
6. explicit control of confounding, leakage and direct intervention pathways.

These are not redundant with the closed FOS/SWIM linkage reconstruction.

## 6. Non-redundancy decision

**PASS — NON-REDUNDANT CAUSAL QUESTION.**

The current C09 operation does not seek to re-establish that accessibility changes are followed by trajectories. That bounded observational/linkage result is already closed.

The unresolved question is specifically whether an **exogenous accessibility intervention** produces a **counterfactually distinguishable subsequent trajectory**.

This is a new falsifiable question and has sufficient incremental information value to justify the current C09 causal-design track.

## 7. Minimal remaining gate

No further generic FOS/SWIM execution is justified for C09.

The next operation is restricted to the already identified EDR candidate and must resolve, using frozen public/preregistered evidence before any execution authorization:

`U_tau → P_tau → Z → T_acc,0/T_acc,1 → Y`

The decisive test is whether `Z` can be shown to modify accessibility itself rather than only incentive exposure or realized behaviour.

If that mapping cannot be established, the EDR candidate must be rejected for C09 causal execution rather than converted into another observational test.
