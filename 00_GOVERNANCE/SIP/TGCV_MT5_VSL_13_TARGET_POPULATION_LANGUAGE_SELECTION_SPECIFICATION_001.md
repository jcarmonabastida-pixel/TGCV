# TGCV — MT5-VSL-13 Target Population / Language Selection Specification 001

**Date:** 2026-09-17  
**Status:** `CLOSED — SELECTION CRITERIA FROZEN; ACTUAL STUDY POPULATION NOT YET SELECTED`

## 1. Purpose

Convert MT5-VSL-12 into an explicit, fail-closed specification for selecting the population, language and administration context of the prospective measurement-validity pilot.

The selection must be determined by the prospective study context, not by C09 treatment results, existing downstream outcomes, expected Value changes, or convenience after inspecting data.

## 2. What can be frozen now

The following design principles are frozen:

1. **Respondent unit:** individual person. The CFPB scale is an individual-level instrument; C09 household records cannot be substituted for individual observations.
2. **Age:** only respondents for whom the frozen scoring procedure provides an applicable age category may be included.
3. **Population:** must be the actual population to which the prospective TGCV measurement study will recruit respondents.
4. **Language:** must be the language in which respondents will actually receive the frozen instrument.
5. **Administration mode:** must be frozen before pilot recruitment and recorded because it affects CFPB scoring.
6. **Geography:** must identify the actual field/site population; C09 geography may not be inherited merely because C09 motivated the methodological development.
7. **Sampling frame:** must be identified independently of Value outcomes.
8. **Eligibility:** must be fixed before observing pilot responses.

## 3. Selection rule

An actual population/language selection is admissible only if all of the following are available:

- a concrete prospective study or pilot context;
- defined geographic/site population;
- identifiable sampling frame;
- individual respondent recruitment mechanism;
- target language;
- administration mode;
- responsible study/fieldwork context;
- justification independent of observed treatment or Value outcomes.

If any of these is absent, the correct disposition is **NOT SELECTED**, not an analyst-invented default.

## 4. Candidate routes considered

### Route A — C09-linked rural-finance population
Could be scientifically relevant because C09 provides the prior TGCV accessibility evidence and a rural-finance context. However, C09 itself is household-level and contains no prospective CFPB respondent frame. Selecting a rural-India population solely because it matches C09 would therefore be an unverified design assumption.

**Disposition:** NOT SELECTED without an independent prospective study context.

### Route B — Spanish-speaking population
The CFPB provides official Spanish questionnaire/user materials, so Spanish can be a technically admissible language route. urlCFPB Financial Well-Being Scale guidehttps://www.consumerfinance.gov/data-research/research-reports/financial-well-being-scale/

However, the existence of an official Spanish version does not identify the prospective population, sampling frame, field setting or study intervention.

**Disposition:** NOT SELECTED without an independent prospective study context.

### Route C — Other target-language population
Admissible only after an explicit translation/adaptation and measurement-validity pathway is defined if no official CFPB version exists.

**Disposition:** NOT SELECTED until a concrete study context is supplied.

## 5. Why no population is silently selected

The current TGCV evidence establishes a methodological route but does not identify a live prospective respondent population. The prior C09 route is explicitly unsuitable for retrospective CFPB scoring because the required item-level measurements were not collected. fileciteturn265file0

The MT5-VSL-11 pilot protocol already requires geography, age eligibility, sampling frame, inclusion/exclusion criteria, target language, administration constraints and individual respondent unit to be frozen before recruitment. fileciteturn263file0

Consequently, selecting rural India, Spain, Spanish-speaking adults, or any other population merely to unblock the protocol would introduce a new substantive design choice not supported by the current empirical programme.
