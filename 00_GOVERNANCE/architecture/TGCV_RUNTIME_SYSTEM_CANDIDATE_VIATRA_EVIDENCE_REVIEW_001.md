**Status:** DEFERRED — not admitted for scientific execution

## Purpose

This review evaluates a concrete runtime-system candidate against S1–S10 of the runtime-system candidate selection gate. It does not constitute admission, instrumentation, execution, or scientific evidence for TGCV.

## Evidence baseline

The evaluated VIATRA repository is an active public repository. Its README describes VIATRA as a model and data transformation framework focused on event-driven and reactive transformations and states that it provides a Java runtime library. The repository's latest commit at the evaluated revision is `ffa111dbb160c0bc55e89ea16430e97a38908662`.

The repository contains a transformation-debugging/runtime-trace component:
- `transformation/plugins/org.eclipse.viatra.transformation.runtime.transformationtrace/...`
- `TransformationTrace.java` contains a serializable transformation trace with activation traces.
- `TransformationDebugger.java` implements an EVM listener and exposes callbacks around transformation activation selection and firing, including `activationFiring` and `activationFired`.

These facts establish instrumentability and transformation-event observability, but they do not by themselves establish the full TGCV observation boundary.

## Decision

**DEFERRED.**

VIATRA is sufficiently concrete and instrumentable to remain a serious candidate, but the evidence is not sufficient for ADMITTED status. The decisive missing element is the independent temporal observation boundary required by the TGCV architectural discrimination programme.

In particular, the existing transformation-trace/debugging facilities cannot be treated automatically as the required independent measurement of R*. Their trace semantics are part of the same runtime system whose transformations are being observed. A TGCV instrumentation layer must therefore be specified so that:
1. event timestamps and ordering are captured independently and immutably;
2. pre-state and post-state observations are explicitly delimited;
3. transformation identity is frozen independently of downstream outcomes;
4. instrumentation provenance and completeness are auditable;
5. the resulting temporal relation is not reconstructed merely from the transformation-space representation.
