## 3. Cross-candidate finding

No existing governed source satisfies all six mandatory bridge components simultaneously.

The recurring bottleneck is not longitudinal data availability alone. It is the independent pre-specification of transformation identity and typed structural relations that can be applied to the longitudinal source without deriving them from `T_acc`, outcomes, or the observed trajectories themselves.

## 4. Governance consequence

No source is admitted to the next discrimination-design gate.

No experiment is selected or authorized.

The result does not falsify TSDI. It establishes only that the current empirical asset base does not yet contain a bridge-qualified instantiation of Ω_T.
