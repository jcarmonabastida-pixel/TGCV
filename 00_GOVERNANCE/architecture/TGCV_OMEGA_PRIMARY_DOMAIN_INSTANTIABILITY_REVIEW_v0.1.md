## 1. Question

Is there an already governed domain in which the Ω-primary object can be instantiated from observable records, with frozen transformation identity/equivalence, typed structural relations, longitudinal correspondence, and an outcome-independent information boundary?

## 2. Review rule

A domain is not admitted merely because it contains a graph, a temporal dataset, or a reconstructible accessibility intervention. The complete Ω-primary tuple must be observable under one frozen construction protocol:

`Ω_T,t = (U_t, ≡_t, R_t)`

with longitudinal correspondence and an information firewall.

## 4. Principal finding

**No existing governed domain currently satisfies the full Ω-primary admissibility package.**

However, the Rust dataset is materially different from the other reviewed candidates: it already exposes stable component identity, version identity, temporal ordering, and an explicit dependency relation in the retained source schema. These are native structural records rather than relations reconstructed from downstream outcomes.

This makes Rust a legitimate **domain candidate for the next architectural instantiation review**, but not evidence that Ω-primary is empirically identified.

## 5. Rust-specific unresolved question

The missing element is not the existence of a structural graph. It is the definition of the transformation universe U and transformation identity/equivalence at the correct semantic level.

`package@version` is demonstrably an observable component identity. It must not automatically be relabelled as a transformation identity.

A valid Ω-primary Rust instantiation would therefore have to specify, ex ante:

1. what counts as a transformation;
2. how transformation identity is derived from the observed package/version/dependency records;
3. how equivalent transformations are canonicalised;
4. which dependency relations are structural relations over those transformations;
5. how adjacent snapshots are corresponded;
6. why none of these definitions uses future outcome, success or value.

The existing Rust record does not yet answer these questions.

## 6. Consequence for the other domains

MT5, C10C-004 and KGFS remain useful as bounded evidence about ex-ante intervention/function definitions and longitudinal structural change, but none currently exposes the complete Ω-primary structural object.

No attempt should be made to combine fragments from different domains into a synthetic Ω-primary evidence claim.
