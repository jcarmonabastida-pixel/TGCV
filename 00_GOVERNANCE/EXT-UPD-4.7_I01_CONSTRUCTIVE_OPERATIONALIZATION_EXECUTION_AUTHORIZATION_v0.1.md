## 1. Authorization scope

A single constructive operationalization attempt for I-01 is authorized.

The only authorized target is:

`Uτ,D (closed) → Pτ,D (pre-outcome) → T_acc,D → ΔT_acc,D`

No downstream Gate D operation is included in this authorization.

## 2. Frozen execution sequence

1. Identify the first native infrastructure-network regime satisfying the frozen constructive criteria.
2. Freeze source provenance and the native unit/state definition.
3. Construct `S_D` and `C_D`.
4. Construct `Uτ,D` independently of feasibility.
5. Verify that `Uτ,D` is finite, discrete or natively bounded.
6. Construct native pre-outcome `Pτ,D`.
7. Evaluate every candidate in `Uτ,D` for membership in `T_acc,D`.
8. Require complete closure of `T_acc,D` without analyst completion.
9. Establish an ordered pair of native states/contexts only if both `T_acc,D` sets are closed.
10. Compute `ΔT_acc,D+` and, where applicable, `ΔT_acc,D−`.
11. Record C1-C5 and all source-level provenance.
12. Stop and classify the attempt if any hard-stop condition is encountered.

## 3. Hard stops

The attempt must stop with **INDETERMINATE** if any of the following is required:

- analyst-invented discretization;
- arbitrary analyst-imposed bounds or thresholds;
- analyst-invented transformation classes;
- outcome-defined accessibility;
- analyst-completed unresolved membership;
- imported Reach, Trajectory, Outcome or Value constructs;
- alteration of frozen TGCV definitions;
- substitution of observed transitions for accessible-transformation membership.

## 4. Result categories

Permitted overall outcomes:

- **CLOSED / CONSTRUCTIVE SUPPORT:** all target objects closed under native evidence and `ΔT_acc,D` defensibly established;
- **INDETERMINATE / BOUNDARY:** at least one target object cannot be closed without prohibited analyst completion;
- **EMPTY:** native universe and feasibility rule are closed and yield no accessible transformations;
- **INELIGIBLE:** no native regime satisfies the frozen constructive selection criteria.

No result category constitutes proof of universal cross-domain generalization.

## 5. Evidence and governance controls

The attempt is outcome-blind and criterion-first. Search may not continue past the first qualifying native regime in order to obtain a favorable result.

No dataset acquisition, empirical dataset processing, causal inference, predictive modeling, optimization, value analysis, Core revision, C-01 revision, third-domain discovery, or external-asset refresh is authorized.

The result must trigger the standard Evidence→Claim impact assessment, propagation, consistency validation and closure before any subsequent scientific gate is opened.

## 6. Authorization effect

**Execution is now authorized for exactly one controlled I-01 constructive attempt.**

No second attempt may be made under this authorization. Any continuation, redesign, additional search, or downstream operation requires a new explicit governance decision.
