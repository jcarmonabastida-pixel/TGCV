# TGCV Integrated Governance Runtime (IGRT)

Current specification: `TGCV_IGRT_v0.1.md`

Status: `CURRENT / CONTROLLED — EXECUTABLE GOVERNANCE LAYER`

IGRT integrates existing governance assets into a lightweight session lifecycle:

`SESSION_START → WORK → SESSION_CLOSE`

It is deliberately subordinate to the canonical scientific state and does not replace RMA, SIP, PMO/SMO, the Scientific Asset Registry or the current-state validator.
