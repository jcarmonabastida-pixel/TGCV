# TGCV — Governance Decision Record: Explicit Architectural Transition Layer

**Date:** 2026-10-01  
**Status:** CLOSED DECISION / GOVERNANCE ACTIVE  
**Decision ID:** ARCH-TRANS-001

## Decision

Introduce an explicit **Architectural Transition / Evidence Assessment Register** into TGCV governance before designing further experiments intended to inform the new Transformational Space Dynamics & Intelligence direction.

The register is a governance layer, not a replacement for the current scientific architecture.

## Rationale

The current Core and Evidence→Claim Matrix were constructed around the inherited architecture centred on `S`, `T_acc`, `ΔT_acc` and downstream Reach/trajectory/outcome/value layers. Recent bounded evidence has made the structural dynamics of transformation space a legitimate architectural question.

The appropriate response is neither to freeze the old architecture as unquestionable nor to replace it in advance of evidence. The transition question must remain explicitly open and empirically discriminable.

## Agreed governance rule

Future evidence can bear **for, against, or independently of** either architectural description. The architecture must not be modified merely to fit an anticipated experimental result.

A future architectural review must trace:

`old architecture/claim → accumulated evidence → detected limitation → candidate new concept → revised architecture/claim`.

Only after such a review may the canonical Core and, where necessary, the Evidence→Claim Matrix receive new versions.

## Current scientific state preserved

- RMA remains v3.37.
- Evidence→Claim Matrix remains v1.44.
- Current Core remains unchanged.
- No C01–C16 claim status is changed by this decision.
- No Transformational Intelligence claim is established.
- No experiment is authorized by this decision.
- No `ΔT_acc → Value` claim is established.

## Next governed step

Before experiment design, use the new transition layer to formulate the architectural discrimination criteria and record which existing evidence is potentially informative, non-discriminating, or insufficient.
