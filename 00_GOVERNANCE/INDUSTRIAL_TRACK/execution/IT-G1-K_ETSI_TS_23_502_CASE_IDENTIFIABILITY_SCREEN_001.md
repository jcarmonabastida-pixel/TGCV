# IT-G1-K — ETSI TS 23.502 Case Identifiability Screen 001

**Date:** 2026-09-10  
**Status:** CLOSED — INSUFFICIENT FOR FORMAL CASE ADMISSION  
**Candidate:** `IT-NOSD-010` — ETSI TS 23.502 V19.6.0  
**Screen type:** bounded public case-identifiability screening

## 1. Purpose

Assess whether the public ETSI/3GPP specification record can identify one concrete industrial decision episode satisfying the frozen IT-G1 criteria.

## 2. Public evidence

ETSI publishes TS 23.502 as a versioned technical specification describing 5GS procedures. Public versions expose dated editions and detailed technical alternatives. For example, the published specification states that some 5GS deployment options depend on operator choices, including NRF/NSSF configuration and roaming arrangements. These are normative/technical alternatives within the specification, not records of individual operator decisions.

The public ETSI specification and version history therefore establish documentary identity, version/date, bounded technical domain, and the existence of alternative configuration paths. They do not identify a particular operator, network deployment, decision date, configuration baseline, decision evidence, or subsequent independently observed outcome corresponding to one industrial decision episode.

## 3. IT-G1 criteria assessment

| Criterion | Status | Assessment |
|---|---|---|
| Concrete industrial decision context | PARTIAL | Operator deployment choices are explicitly contemplated, but no individual decision episode is identified. |
| Explicit system boundary | PASS at specification level | 5G System procedures are bounded by TS 23.502. |
| Bounded reproducible unit | NOT CLOSED | Specification clauses are not equivalent to an individual industrial decision unit. |
| Decision-time temporal frame | NOT CLOSED | Publication/version dates do not identify an operator decision time. |
| Applicable normative context | PASS | Versioned specification is publicly identifiable. |
| Decision unit / organisation identity | NOT CLOSED | No individual operator or organisation decision is publicly identified. |

## 4. Decision

**IT-G1-K = INSUFFICIENT FOR FORMAL CASE ADMISSION.**

The specification is a strong documentary candidate for describing an industrial decision domain and accessible technical alternatives, but the public evidence does not identify a complete individual industrial decision episode. Treating a specification version or a clause as the industrial decision itself would collapse normative specification identity into the decision episode and would violate the frozen IT-G1 unit-of-analysis requirement.

No IT-G2 assessment is authorized from this screen.

## 5. Methodological significance

This is a useful negative screening result: a richly versioned technical standard can expose a structured transformation space and explicit alternative paths while still failing to expose the historical state/context and actor-specific decision event needed for a reproducible industrial case.
