## Audit scope

Static audit of the v0.5 repair against Audit 004, the IT-METH-I blind executor specification and the actual FAA AMOC evidence provenance established in GitHub. It does not establish an independent executor, does not authorize reconstruction 002 and does not perform the dry-run.

## 1. Evidence model alignment — PASS

The harness no longer assumes that the original FAA/EASA source documents exist as local filesystem files. The declared evidence boundary is now a set of exact documentary records already persisted in the canonical TGCV GitHub repository.

The manifest records, for each documentary record:

- canonical repository path;
- Git blob SHA as the immutable repository-content anchor;
- source role;
- source locator describing the external public evidence represented by the record.

This matches the actual provenance chain without fabricating local copies of primary FAA/EASA documents.

## 2. Manifest integrity — PASS

The manifest is externally supplied to the harness and is not generated by the harness. Each entry requires `repo_path` and `source_role`, plus at least one content anchor (`git_blob_sha` or `sha256`). Duplicate repository paths are rejected. Git blob SHA and SHA-256 formats are validated.

## 3. GitHub documentary-record verification — PASS

For each declared record, v0.5:

- resolves it beneath an explicit repository root;
- rejects paths escaping the repository root;
- rejects paths outside the declared evidence root;
- rejects symlinks and unavailable files;
- recomputes the Git blob SHA from the checked-out bytes;
- optionally verifies a SHA-256 anchor;
- records the observed values separately from the declaration.

This establishes integrity of the checked-out documentary records, not authenticity of the external source itself.

## 4. Source/documentary distinction — PASS

The manifest explicitly distinguishes `TGCV_DOCUMENTARY_RECORD` from `TGCV_GOVERNANCE_RECORD`. The latter is retained only as methodological context and is not represented as primary external evidence.

The harness does not claim that GitHub files are copies of the FAA/EASA originals. The source locator records what public evidence the TGCV documentary record represents.

## 5. Runtime filesystem isolation — PASS / NOT VERIFIED BY DESIGN

The harness retains:

`RUNTIME_FILESYSTEM_ISOLATION_STATUS=NOT_VERIFIED`

`RECONSTRUCTION_001_ACCESS_STATUS=NOT_VERIFIED`
