## 1. Purpose

The Architectural Research Map (ARM) is a controlled map of the TGCV scientific architecture, analytical layers, evidence boundaries, dependencies and open research operations. It is an architectural control artifact and does not introduce a new scientific claim, empirical result or ontological primitive.

## 2. Current scientific architecture

The current ontological Core is:

`Core_ontological = S`

The accessible transformation space is an analytical representation derived from state and contextual conditions:

`T_acc,t = {τ ∈ Uτ | Pτ(S_t,C_t,L)=1}`

The central dynamic quantity is:

`ΔT_acc(t,t+1) = T_acc,t+1 ≄ T_acc,t`

`T_acc` is analytically indispensable for representing accessibility change, while TR-131 established that it is not ontologically independent of `S`.

Interaction `I` remains an explanatory mechanism variable and not a Core primitive.

The controlled analytical chain is:

`mechanism → (S,C) → (S’,C’) → ΔT_acc → ΔReach → ΔTrajectory → Outcome → Value`

Downstream elements are analytical layers, not automatically established causal consequences.

## 3. Architectural layers

### Layer A — Ontological state
- `S`: minimal ontological state.
- No independent primitive `I`.

### Layer B — Accessible transformations
- `T_acc`: transformations accessible under relevant state/context/constraint conditions.
- `ΔT_acc`: change in accessible transformation membership.
- Complete ex-ante enumeration of `T_acc` is not a universal methodological prerequisite; operational closure is case-dependent and must remain outcome-independent.

### Layer C — Reach and trajectory
- `Reach`: transformations or states reachable through subsequent admissible transitions.
- `Trajectory`: ordered downstream development through time.

### Layer D — Outcome and value
- `Outcome`: observed subsequent result.
- `Value`: requires an additional analytical and evidentiary argument.
- No current evidence establishes that `ΔT_acc` is sufficient for value creation.

### Layer E — Cross-domain translation
The translation architecture tests whether the same minimal analytical distinctions can be represented across domains without importing domain-specific semantics into the TGCV Core. D-OPS-22 established bounded translational non-redundancy without proving superiority; D-OPS-23 froze the minimal transversal translation protocol.
