# Learning Resources

Supplementary tutorials, guides, exercises, research notes and learning paths that are not part of the core book chapters.

## Research notes

Reader-facing evidence notes are authored natively in both languages and stored in paired language folders:

- `research-notes/es/`
- `research-notes/en/`

Each bilingual pair shares a stable content ID but maintains independent editorial status. Internal research identifiers and source paths belong in metadata, not in the reader-facing prose.
