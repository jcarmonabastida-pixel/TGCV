# TV-DIA-001 — Accessible transformation space sequence

**Status:** Draft  
**Source:** `source/accessible-transformation-space-sequence.mmd`  
**Purpose:** Distinguish the accessible transformation space from a transformation that is actually realised and from the subsequent system state and re-evaluated accessible space.

The diagram is an analytical teaching aid. Its arrows do not assert a universal causal law. In particular, accessibility does not imply realisation, and the sequence does not imply that Value necessarily follows.

Spanish and English captions and alternative text must be maintained with the corresponding chapter content. The diagram source is language-neutral.
