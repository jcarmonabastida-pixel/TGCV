# Accessible transformation space sequence

**Asset ID:** TV-DIA-001

**Owner:** TRANSFORMATIONAL VALUE editorial project

**Format:** Mermaid flowchart; language-neutral source  
**Purpose:** Distinguish the accessible transformation space from a transformation that is actually realised, the successor system state and the re-evaluated accessible space.

## Source provenance and interpretation

The diagram expresses the analytical sequence used in Chapter 3:

`system state and relevant conditions → accessible transformation space → possible realisation → successor state → next accessible transformation space`.

Its arrows organise the analytical relationship. They do not assert a universal causal law. In particular, accessibility does not imply realisation, and the sequence does not imply that Value necessarily follows. The diagram does not depict a complete trajectory or a value function.

The source is a shared conceptual teaching asset for the Spanish and English versions of Chapter 3. It is not derived from one empirical domain and does not claim that all systems share the same transformation semantics.

## Spanish reader-facing text

**Caption**

El espacio de transformaciones accesibles se evalúa a partir del estado del sistema y de las condiciones relevantes. Una transformación accesible puede realizarse o no; si se realiza, conduce a un estado sucesor desde el que se evalúa el siguiente espacio accesible.

**Alternative text**

Diagrama horizontal de cinco etapas: estado y condiciones relevantes; espacio de transformaciones accesibles; transformación realizada; estado sucesor; y siguiente espacio de transformaciones accesibles. Una flecha continua conecta el estado con la evaluación del espacio. Una flecha discontinua indica que una transformación accesible puede o no realizarse. Si se realiza, conduce al estado sucesor, desde el que se evalúa el siguiente espacio. Una nota recuerda que accesibilidad, realización, trayectoria, resultado y valor son conceptos distintos. Las flechas representan una secuencia analítica, no una ley causal universal.

## English reader-facing text

**Caption**

The accessible transformation space is evaluated from the system state and relevant conditions. An accessible transformation may or may not be realised; if it is, it leads to a successor state from which the next accessible space is evaluated.

**Alternative text**

A horizontal five-stage diagram: system state and relevant conditions; accessible transformation space; realised transformation; successor state; and next accessible transformation space. A solid arrow connects the state to the evaluation of the accessible space. A dashed arrow indicates that an accessible transformation may or may not be realised. If realised, it leads to the successor state, from which the next space is evaluated. A note distinguishes accessibility, realisation, trajectory, outcome and value. The arrows represent an analytical sequence, not a universal causal law.
