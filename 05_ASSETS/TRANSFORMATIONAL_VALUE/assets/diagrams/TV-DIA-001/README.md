# Accessible transformation space sequence

**Asset ID:** TV-DIA-001

**Source format:** Mermaid flowchart  
**Purpose:** Distinguish the accessible transformation space from a transformation that is actually realised, the successor system state and the re-evaluated accessible space, while showing that next-period conditions also inform that evaluation.

## Conceptual interpretation

The diagram expresses the analytical sequence used in Chapter 3:

`system state and relevant conditions → accessible transformation space → possible realisation → successor state → next accessible transformation space`.

The next accessible space is evaluated from both the successor system state `Sₜ₊₁` and the next relevant conditions `Cₜ₊₁, Lₜ₊₁`. These conditions are shown as an independent input: the diagram does not imply that a realised transformation produces all contextual conditions or constraints.

The arrows organise the analytical relationship. They do not assert a universal causal law. In particular, accessibility does not imply realisation, and the sequence does not imply that value necessarily follows. The diagram does not depict a complete trajectory or a value function.

The non-directional labelled connector to the distinction note marks a conceptual clarification, not an additional process stage.

The source is a shared conceptual teaching asset for the Spanish and English versions of Chapter 3. It is not derived from one empirical domain and does not claim that all systems share the same transformation semantics.

## Spanish reader-facing text

**Caption**

El espacio de transformaciones accesibles se evalúa a partir del estado del sistema y de las condiciones relevantes. Una transformación accesible puede realizarse o no; si se realiza, conduce a un estado sucesor. El siguiente espacio accesible se evalúa considerando tanto ese estado como las nuevas condiciones relevantes.

**Alternative text**

Diagrama horizontal con seis nodos de proceso o entrada: estado del sistema y condiciones relevantes iniciales; espacio de transformaciones accesibles; transformación realizada; estado sucesor del sistema; nuevas condiciones relevantes; y siguiente espacio de transformaciones accesibles. Una flecha continua conecta el estado inicial con la evaluación del espacio accesible. Una flecha discontinua indica que una transformación accesible puede realizarse o no. Si se realiza, conduce al estado sucesor. El siguiente espacio se evalúa a partir del estado sucesor y, de forma independiente, de las nuevas condiciones relevantes. Una conexión no direccional y etiquetada vincula el espacio accesible con una nota que distingue accesibilidad, realización, trayectoria, resultado y valor. Las flechas representan relaciones analíticas, no una ley causal universal.

## English reader-facing text

**Caption**

The accessible transformation space is evaluated from the system state and relevant conditions. An accessible transformation may or may not be realised; if it is, it leads to a successor state. The next accessible space is evaluated from both that state and the next relevant conditions.

**Alternative text**

A horizontal diagram with six process or input nodes: initial system state and relevant conditions; accessible transformation space; realised transformation; successor system state; next relevant conditions; and next accessible transformation space. A solid arrow connects the initial state to the evaluation of the accessible space. A dashed arrow indicates that an accessible transformation may or may not be realised. If realised, it leads to the successor state. The next space is evaluated from the successor state and, independently, from the next relevant conditions. A non-directional labelled connector links the accessible space to a note distinguishing accessibility, realisation, trajectory, outcome and value. The arrows represent analytical relationships, not a universal causal law.
