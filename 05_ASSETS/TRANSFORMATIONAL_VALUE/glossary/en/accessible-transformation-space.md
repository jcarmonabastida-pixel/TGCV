# Accessible transformation space

An analytical representation of the set of transformations a system can perform under a specified state and relevant conditions. In the current TGCV model, it is expressed as a function of the system state and the relevant conditions and constraints.

The space describes which transformations are accessible under those conditions; it does not indicate which transformations will actually be realised. It must therefore be distinguished from realised transformations, the trajectory resulting from them, and subsequent outcomes.

Its boundaries depend on how the system, the candidate transformation universe and the accessibility predicate are defined for the case under analysis. It should not be assumed that every case requires the prior enumeration of every conceivable transformation.

**Notation:** (T_{acc}).

**Key distinction:** an accessible transformation is not necessarily executed, and its execution does not necessarily create value.
