# 02 — Literature and SLR working archive

This directory is the **historical SLR working/archive surface**.

It contains literature-review material, source dossiers, search logs, schemas, evidence/fact-bank artefacts and historical TGCV scientific gates produced during the SLR phase.

## Canonical-science rule

Files in this directory are **not to be treated as an invisible or disposable archive**. Any scientific gate, audit, operational specification, domain analysis, or other research-bearing artifact that can materially affect a future scientific operation must be discoverable through the canonical external-science registry and governance controls.

The canonical integration surface is:

`02_EXTERNAL_SCIENCE/`

Historical files remain here until an explicit migration/reclassification operation records their canonical destination. They must not be silently moved, deleted, rewritten, or promoted.

## Mandatory reuse check

Before initiating a new scientific gate, audit, experiment, domain selection, operationalisation, dataset search, or technical feasibility study, the investigator must consult:

1. `00_GOVERNANCE/` current and historical control surfaces;
2. `02_EXTERNAL_SCIENCE/` canonical science registry;
3. the SLR archive in this directory, when indicated by the registry.

Failure to perform this reuse check is a governance nonconformance and may invalidate a claim of independent "from-scratch" discovery.
