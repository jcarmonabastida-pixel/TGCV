# TGCV Core & Ontology — Post-EMP-1.1 Status v0.2

**Status:** Internal scientific consolidation — NOT a theory freeze

## 1. Purpose

This document records the post-EMP-1.1 evidential status of the TGCV core and ontology. It distinguishes what the experiment supports from what remains theoretical, provisional, or untested.

## 2. Core relation

The central proposed relation remains:

`S → T_acc = F(S,C,L) → ΔT_acc → ΔTrajectory → Value`

The scientific object is the modification of the transformations accessible to a system through interactions and conditions represented by the state/context/constraints.

## 3. Ontological status of principal constructs

| Construct | Current status | Empirical implication |
|---|---|---|
| System state `S` | foundational representation | used in operationalisation; not independently validated as a universal ontology |
| Context `C` | provisional construct | contributes to the proposed accessibility function; domain generality remains open |
| Constraints/resources `L` | provisional construct | accessibility predicates can condition on them; universal sufficiency not established |
| Transformation universe `T` | operational construct | must be declared by each experiment; not assumed universal in its current form |
| Accessible set `T_acc` | central test construct | computational evidence supports predictive usefulness of the tested representation |
| Change in accessibility `ΔT_acc` | theoretical central construct | supported indirectly through structural/accessibility intervention; requires further direct validation |
| Trajectory `ΔTrajectory` | downstream theoretical construct | not established by EMP-1.1 |
| Value | downstream programme objective | not established by EMP-1.1 |

## 4. What EMP-1.1 changes

EMP-1.1 increases the evidential status of the accessibility component of the theory. It does not license the conclusion that every layer of the causal chain has been empirically demonstrated.

The strongest defensible interpretation is that relational accessibility information, as operationalised in the sealed experiment, contained predictive information beyond the baseline representation and beyond accessibility count alone.

## 5. What remains open

The following remain explicit research questions:

- whether the same relation survives independent operationalisation;
- whether the effect generalises across domains;
- which components of `S,C,L` are necessary or sufficient;
- whether `ΔT_acc` predicts trajectory changes independently of confounds;
- whether and how accessibility changes translate into value;
- where the theory reaches boundary conditions or fails.

## 6. Anti-retrospective-revision rule

No ontology term is promoted to empirical fact solely because it was useful in explaining EMP-1.1. The sealed experiment is evidence about its frozen operationalisation, not a warrant for post-hoc ontological certainty.

## 7. Replication principle

Future replication must independently specify the operationalisation, candidate transformation universe and accessibility predicates before observing the replication outcomes.

## 8. Current theoretical judgement

**Core:** retained.

**Ontology:** provisionally stabilised, not final.

**Accessibility hypothesis:** empirically supported in the tested computational setting.

**Trajectory/value layers:** open.

**Generalisation:** unestablished.

**Scientific priority:** independent replication, boundary-condition testing and progressive formalisation.
