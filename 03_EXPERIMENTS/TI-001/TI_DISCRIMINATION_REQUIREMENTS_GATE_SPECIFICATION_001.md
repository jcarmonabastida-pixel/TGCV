# TI Discrimination Requirements Gate Specification 001

## Purpose
Formalize the minimum scientific requirements that future evidence would need to satisfy to discriminate the six open TI questions identified after TI-001 V011. This specification is a requirements register, not a future experiment design.

## Requirements

| ID | Open question | Minimum discrimination requirement |
|---|---|---|
| Q1 | Construct validity | Evidence must distinguish incorporation of future transformation structure from at least the principal task/interface and simpler-heuristic alternatives compatible with V011. |
| Q2 | Presentation dependence | Evidence must permit separation of future-structure sensitivity from presentation/order effects through independently observable comparisons across relevant presentation conditions. |
| Q3 | Null/control behaviour | Evidence must separate baseline/control variability from response changes attributable specifically to the presence of future-structure information. |
| Q4 | Robustness | Evidence must test whether the observed decision-level pattern persists under independently specified operational changes rather than merely repeating the same V011 setting. |
| Q5 | Mechanism | Evidence must distinguish at least competing mechanism-level explanations that make different observable predictions about how future-structure information affects present decisions. |
| Q6 | Relation to TGCV | Evidence must establish, independently and traceably, any bridge from decision-level behaviour to changes in accessible transformation space before any claim involving later value is considered. |

## Cross-cutting requirements
1. The discriminating observation must be identifiable before inspecting the outcome.
2. Alternative explanations must remain explicitly represented until evidence discriminates them.
3. A result cannot be treated as discrimination merely because it is statistically or operationally reproducible.
4. Reproducibility and construct validity are distinct evidential properties.
5. Any future evidence must preserve the distinction among present decision, future transformation structure, transformation-space consequences, and value endpoints.
6. No single result from V011 is to be retrospectively reclassified as resolving any open question.

## Boundary
This gate does not:
- specify V012;
- select a task, fixture, model, sample size, randomization, estimator, or execution protocol;
- authorize scientific execution;
- upgrade claims;
- modify the TGCV Core;
- mutate V011 scientific results;
- select a preferred alternative explanation.

## Disposition
If Q1–Q6 and all cross-cutting requirements are explicitly represented, the disposition is `TI_DISCRIMINATION_REQUIREMENTS_FORMALIZED`.
