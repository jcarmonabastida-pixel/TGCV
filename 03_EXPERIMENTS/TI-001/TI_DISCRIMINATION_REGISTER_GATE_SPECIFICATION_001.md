# TI Discrimination Register Gate Specification 001

## Purpose
Formalize a discrimination register from the six scientific open questions identified after TI-001 V011. The register shall state, for each question, the unresolved issue, compatible alternative explanations, discriminating observables, informative result patterns, and non-claims.

## Inputs
- TI-001 V011 closed scientific evidence.
- TI Open Questions and Discrimination Gate result: TI-OPEN-QUESTIONS-AND-DISCRIMINATION-GATE-001.
- Evidence consolidation disposition.
- Evidence→Claim Matrix v1.35.

## Required register entries
Exactly six entries, corresponding to Q1–Q6:
1. Construct validity.
2. Presentation dependence.
3. Null/control behaviour.
4. Robustness.
5. Mechanism.
6. Relation to TGCV transformation space and, only if separately warranted, value.

Each entry must contain:
- question_id;
- unresolved_issue;
- compatible_alternatives;
- discriminating_observables;
- informative_result_patterns;
- current_non_claims.

## Scientific boundary
The register must preserve:
- V011 evidence as bounded experimental evidence.
- No claim upgrade.
- No causal Delta T_acc -> Delta V claim.
- No transversal validity claim.
- No universal Transformational Intelligence capability claim.
- No explanatory or predictive superiority claim.
- No Core modification.

## Gate boundary
This gate does not:
- define a V012 experiment;
- select a fixture;
- select a model;
- define sample size, randomization, execution protocol, or analysis estimator for a future experiment;
- authorize execution;
- mutate V011 scientific results;
- modify claims or the TGCV Core.

## Disposition
If all six register entries are complete and the boundaries are preserved, the final disposition is TI_DISCRIMINATION_REGISTER_FORMALIZED.
