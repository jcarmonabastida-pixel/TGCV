## Frozen algorithm

For the ordered unit universe

```text

```

and seed

```text

```

the permutation is generated by the following deterministic Fisher-Yates procedure.

For each descending index

```text
i = 255, 254, ..., 1
```

perform exactly these operations:

1. Construct the ASCII byte sequence representing the string `f"{seed}:{i}"`.
2. Compute `digest = SHA256(input_bytes)`.
3. Interpret the complete 32-byte digest as one unsigned big-endian integer.
4. Compute `j = integer mod (i + 1)`.
5. Swap the elements at positions `i` and `j`.

No other digest truncation, encoding, integer interpretation, or range-reduction rule is permitted by this specification.

## Assignment

After the permutation is complete, positions `0..127` receive

```text

```

and positions `128..255` receive

```text

```

Therefore the assignment is deterministic and balanced at 128 control / 128 treatment units.
