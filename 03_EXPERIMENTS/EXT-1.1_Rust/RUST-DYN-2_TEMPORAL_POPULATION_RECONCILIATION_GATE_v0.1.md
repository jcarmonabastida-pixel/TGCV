## Purpose

Determine whether the historical Rust Potential Reach temporal reconstruction used the same temporal population as the currently frozen DR-035 rule.

This is a historical-reconciliation audit, not RUST-DYN-2 execution and not new scientific evidence about Reach.

## Historical population

The historical temporal reconstruction artifact reports 516,061 paired focal-version transitions and used temporal ordering by `(created_at, id)`.

This historical rule is retained exactly as historical provenance. It must not be rewritten.

## Current population

DR-035 defines the current primary population as:

1. origins grouped by `package_id`;
2. ordered exclusively by `created_at`;
3. exact timestamp ties excluded rather than secondarily ordered;
4. adjacent consecutive origins only;
5. earlier origin to later origin.

## Reconciliation object

The audit shall construct two explicit pair sets over the same frozen dataset:

`P_hist = historical temporal pair population`

`P_DR035 = population generated by DR-035`

Each pair shall be represented canonically as `(origin_a_version_id, origin_b_version_id)`.

The audit shall compute:

- `|P_hist|`;
- `|P_DR035|`;
- `|P_hist ∩ P_DR035|`;
- `|P_hist \ P_DR035|`;
- `|P_DR035 \ P_hist|`;
- exact membership hashes for both sets;
- timestamp-tie counts;
- packages affected by historical secondary ordering, if any.

## Decision rule

### RECONCILED — EXACT

If `P_hist == P_DR035`, the historical temporal population is compatible with DR-035 and may be reused as historical evidence subject to the separate semantic compatibility checks already established in DR-041.

### RECONCILED — PARTIAL

If the populations differ, the historical Potential Reach semantic work remains reusable, but historical temporal numerical results shall not be imported as evidence for current RUST-DYN-2 unless they are demonstrably restricted to the common population and semantics.

### RECONCILIATION FAILURE

If the historical population cannot be reconstructed deterministically from preserved provenance, this limitation must be recorded. No equivalence may be inferred from equal aggregate counts alone.
