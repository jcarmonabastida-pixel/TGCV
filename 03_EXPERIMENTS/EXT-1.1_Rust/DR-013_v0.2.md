# DR-013 v0.2 — Data/representation readiness gate

## Status

PRE-DATA FREEZE / PASS FOR PIPELINE DESIGN

## Invariants

- **DR-013.1 Temporal integrity:** structural state is computed only from the declared historical snapshot; outcomes are temporally separated.
- **DR-013.2 Dependency determinism:** semver requirements are evaluated by a pinned deterministic resolver/rule set.
- **DR-013.3 Identity integrity:** package and version identities are stable and joins use canonical identifiers.
- **DR-013.4 Outcome coverage:** daily-download observations are measured for the declared window; missing/censored observations are retained as flags.
- **DR-013.5 Accessibility independence:** T_acc uses structural information only and cannot depend on downloads or future information.
- **DR-013.6 Reproducibility:** all inputs, source refs, code version, parameters and resulting artifacts receive provenance and SHA-256 hashes before FREEZE.

## Required pre-freeze checks

1. Verify the historical index snapshot ref and its commit SHA.
2. Verify the download archive file and SHA-256 after user upload.
3. Implement and test the accessibility predicate on synthetic fixtures.
4. Verify that state changes with no change in T_acc are represented.
5. Verify additions and removals from T_acc.
6. Verify yanked versions and unsatisfied semver requirements.
7. Verify no future/current index metadata enters the historical calculation.

## Decision rule

No confirmatory EXT-1.1 execution is permitted until all six invariants PASS and the real input artifacts are frozen.
