## 3. Provenance findings

### 3.1 CONFIRMATORY_RESULTS

The result file was archived by commit `67183f51ef23dd3d91e573738c5f9bee376074b6` on 2026-08-27. Its content identifies the experiment as `TGCV-EMP-1.1` and records a generic computational result: baseline B versus TGCV representation R, predictive LogLoss/AUC metrics, controls, and a 5,000-pair structural intervention.

The canonical EMP-1.1 computational provenance record states that the historical MVE-1.0 executable implementation was not recovered and that EMP-1.1 used a newly specified operationalisation. It also states that exact independent re-execution from the repository was not established.

Therefore the archived confirmatory result is not traceably attributable to the later Rust-specific R* v0.2 implementation.

### 3.2 STRUCTURAL_INTERVENTION_RESULTS

The structural result file was archived by commit `6a0db7fc26343639bc528d0410b3a60f7e0535d2` on 2026-08-27, immediately after the confirmatory-results commit. The repository comparison shows that the Rust-specific `07_CODE/experiments/structural_intervention.py` script was added later, not present in the result-producing commit lineage.

Consequently, the current Rust structural-intervention script cannot be established as the executable provenance of the archived 5,000-pair result.

### 3.3 Temporal incompatibility with R* v0.2

R* v0.2 was frozen later and is explicitly the restricted resolver for EXT-1.1 Rust. The conformance gate subsequently established that its current implementation matches the frozen specification and dataset.

The archived EMP-1.1 results therefore predate the R* v0.2 freeze and cannot be assumed to have used R* v0.2 merely because the files now coexist in the repository.

### 3.4 Dataset/protocol boundary

The Rust execution package and amended CHR-MICRO-3 protocol define a snapshot-only historical resolver route, with explicit snapshot commits and an independent version-ID bridge. The existing EMP-1.1 confirmatory result record does not contain sufficient resolver/dataset/hash provenance to demonstrate that this route generated the reported predictive and intervention results.

The Rust execution manifest records an independently closed snapshot-only micro-execution, but this is not evidence that the archived EMP-1.1 confirmatory model fit used the same inputs or resolver.

## 5. Gate decision

**TRACEABILITY RECONCILIATION = FAIL / BLOCKED FOR CONFIRMATORY ACCEPTANCE.**

This is **not a scientific failure of the reported effect**. It is a provenance failure for treating the archived result as confirmatory evidence under the current EXT-1.1/R* v0.2 protocol.

The archived results must be retained as historical empirical records of the specified EMP-1.1 operationalisation, with their existing provenance boundary. They must not be deleted, overwritten, or silently relabelled as R* v0.2 results.

## 6. Consequence

1. The R* v0.2 conformance PASS remains valid and closed.
2. The archived EMP-1.1 result remains documented historical evidence, but is not accepted as confirmatory evidence for the R* v0.2 Rust branch.
3. No scientific claim may be based on the numerical results as though they were generated by R* v0.2.
4. No new counterfactual is to be invented: the pre-registered/frozen T_acc counterfactual micro-fixture remains the designated A/B/C asset.
5. The next executable gate is a **controlled reconstruction/re-execution of the already specified EXT-1.1 Rust confirmatory analysis**, using the frozen R* v0.2, frozen dataset hash, and fully recorded code/configuration/environment.

## 7. Required closure evidence for the next gate

The reconstruction must produce, before confirmatory interpretation:

- exact source commit and blob hashes for all result-producing code;
- exact R* v0.2 spec and implementation hashes;
- exact dataset/input hashes;
- frozen model/configuration parameters;
- seeds and train/test split identifiers;
- explicit linkage to the pre-registered T_acc counterfactual;
- environment/runtime versions;
- deterministic or independently repeated execution evidence;
- a result manifest linking every reported statistic to its producing artifact.

**Final disposition:** archived results retained; confirmatory acceptance denied pending controlled reconstruction.
