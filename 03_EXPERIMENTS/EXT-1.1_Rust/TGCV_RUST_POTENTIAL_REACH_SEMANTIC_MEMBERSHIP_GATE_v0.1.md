# TGCV — Rust Potential Reach Semantic Membership Gate v0.1

**Status:** PASS — BOUNDED DEPTH-1 POTENTIAL REACH MEMBERSHIP CONTRACT FROZEN

## Purpose

Define, before computing Reach, when a structurally constructed Rust successor is a member of a bounded **potential Reach** object, without importing execution, resolver outcomes, outcome, value, or future activity.

## Locked architecture

`Core_ontological = S`

`T_acc,t = {(e_o,τ) | P_τ(e_o,t)=1}`

`ΔT_acc` remains the primary differentiated object.

`Reach` is downstream from `T_acc` and is not identical to it.

## 1. Starting configuration

For this empirical instantiation, the dataset does **not** provide historical Cargo lockfiles or resolver-selected dependency configurations. Therefore no observed resolved configuration may be fabricated.

The starting object for this bounded potential Reach construction is the **declaration-induced structural configuration**:

`C_decl(e_o,t) = {(p_d, r) | declaration from focal version e_o to target package p_d has requirement r and r is supported under frozen R* v0.2}`.

This is explicitly a declaration configuration, not an executed or Cargo-resolved configuration.

## 2. Accessible transformation

A candidate transformation is:

`τ=(e_o,p_d,v_d)`

with fixed identity:

`τ_id=(origin_version_id,target_package_id,target_version_id)`.

Membership in `T_acc,t` requires the already frozen Rust accessibility predicate. This gate does not redefine `P_τ`.

## 3. Successor semantics

For an accessible `τ`, define the depth-1 potential successor:

`Succ(C_decl,τ) = C_decl \ {(p_d,r) : any r} ∪ {(p_d,v_d)}`

where the replacement is represented canonically as a target-package → target-version assignment.

The successor is a **potential configuration** under the analytical transformation semantics. It is not claimed to be a Cargo resolver output or an execution state.

## 4. Semantic membership condition

A successor belongs to `Reach¹_pot(e_o,t)` iff all of the following hold:

1. the focal configuration is canonical;
2. `τ ∈ T_acc,t` under the frozen accessibility predicate;
3. target package and target version are canonical and present in the dataset;
4. the target version is admissible for the declaration requirement under frozen R* v0.2;
5. successor construction replaces the target-package declaration/assignment without modifying unrelated packages;
6. no execution event is required;
7. no observed outcome is required;
8. no future activity is required;
9. the successor is deterministically canonicalizable.

Formally:

`Reach¹_pot(C,t) = {C} ∪ {Succ(C,τ) | τ ∈ T_acc,t ∧ Admissible(τ,C,t)}`.

## 5. Multiple satisfying versions

Distinct target-version identities produce distinct potential successors when they produce distinct canonical configurations.

The construction therefore does **not** apply a max-version or single-version resolver selection rule.

This is deliberate: `Reach¹_pot` represents the set of potential structural alternatives, not the single version Cargo would eventually select.

## 6. Unsupported and unresolved cases

- `UNSUPPORTED` requirement/version: excluded from resolved accessibility and Reach membership.
- `UNRESOLVED` identity: excluded from Reach membership and retained as unresolved data.
- Neither status is converted into `P=0` silently.
- No coercion of unsupported SemVer syntax is allowed.

## 7. Distinction from T_acc

`T_acc` contains **transformations**.

`Reach¹_pot` contains **potential successor configurations** generated by those transformations.

Thus a transformation and the configuration it could generate are analytically distinct objects:

`τ ∈ T_acc` does not imply `τ = C'`.

The map `τ → Succ(C,τ)` is the bridge.

## 8. Distinction from execution

The following implication is explicitly forbidden:

`Succ(C,τ) ⇒ Exec(τ)`.

Potential reachability means only that the successor is structurally constructible under the frozen analytical rules.

## 9. Temporal comparison

For paired times `t0,t1`, Reach comparison may be computed only after independently reconstructing `T_acc,t0` and `T_acc,t1` under the frozen temporal/accessibility contracts.

No outcome-optimized pairing or post-origin activity may be introduced.

`ΔReach = Reach¹_pot,t1 ≄ Reach¹_pot,t0` is therefore a derived structural comparison, not a causal claim.

## 10. Falsifiers

**PR-S1:** the starting declaration configuration cannot be represented without silently importing resolver semantics.

**PR-S2:** successor membership requires execution or outcome information.

**PR-S3:** `Admissible(τ,C,t)` cannot be evaluated independently of the outcome.

**PR-S4:** multiple admissible target versions cannot be represented as distinct potential alternatives without arbitrary selection.

**PR-S5:** Reach¹_pot collapses to T_acc membership with no configuration-level remainder.

**PR-S6:** successor identity is non-deterministic or row-order dependent.
