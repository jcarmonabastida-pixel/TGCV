# TGCV — VSL Synthetic Minimum v0.1
## Frozen Synthetic Fixture

**Status:** FROZEN FIXTURE — PRE-RUNNER  
**Specification:** `00_GOVERNANCE/SIP/TGCV_VSL_SYNTHETIC_MIN_v0.1_SPECIFICATION.md`  
**Outcome definition:** `00_GOVERNANCE/SIP/TGCV_VSL_SYNTHETIC_MIN_OUTCOME_DEFINITION_v0.1.md`

## Purpose

This fixture implements only the frozen synthetic state and case requirements needed to test the external VSL architecture.

It does not implement the experimental runner.

It does not introduce additional Value assumptions.

## Frozen state model

`S=(q,r)`

- `q`: operational capability level
- `r`: operational resource level
- both are non-negative integers

Baseline:

`S0=(10,10)`

Outcome:

`O(S)=q+0.5r`

Therefore:

`O0=15`

Value:

`V*=O`

## Accessibility model

Accessibility is represented separately from the state:

`T_acc`

The fixture MUST NOT store `T_acc` inside `S`.

The outcome calculation MUST operate only on `S1=(q,r)`.

## Required separation

The fixture contains independent conceptual objects:

1. baseline/final state;
2. accessibility state;
3. case/transition metadata.

The outcome function receives only the final state.

The VSL receives only the independently computed outcome.

The following dependency is prohibited:

`T_acc → O`

and:

`T_acc → V*`

## T4 control

T4 is deliberately independent of accessibility.

Its `q=12` final state must be generated by an exogenous synthetic factor in the fixture.

That factor must not inspect `T_acc`.

## Expected identifiability

The fixture must make it possible to observe both:

- `ΔT_acc ≠ 0` with `ΔV*=0` (T2/NC2);
- `ΔT_acc=0` with `ΔV*>0` (T4).

Therefore Value cannot be operationally identical to accessibility change in this fixture.

## Fixture audit requirements

Before runner construction, audit:

- exact baseline state;
- exact final states;
- exact accessibility deltas;
- exact outcome values;
- T4 independence;
- absence of accessibility variables in outcome inputs;
- absence of Value variables in state transitions;
- exact correspondence to the frozen specification.

## Claim boundary

It is not execution evidence.

It does not establish causal validity, empirical Value, generality, C09 validity, or any real-world Value claim.
