# 02_EXTERNAL_SCIENCE — Canonical Scientific Asset Registry

## Purpose

`02_EXTERNAL_SCIENCE/` is the canonical registry and integration surface for **research-bearing scientific knowledge produced or adopted by TGCV that must be reusable by future gates, audits, experiments, domain-selection decisions or operationalisation work**.

It complements, and does not replace, the SLR archive in `02_LITERATURE/`.

## Boundary with 02_LITERATURE

- `02_LITERATURE/` remains the historical SLR working/archive surface: searches, source dossiers, evidence/fact-bank material and SLR process artefacts.
- `02_EXTERNAL_SCIENCE/` contains the canonical registry of research-bearing artefacts whose prior existence must be considered before new scientific work is initiated.
- An artefact may remain physically in `02_LITERATURE/` while being registered here. Physical migration is a separate controlled operation and is never implied by registration.
- Historical artefacts remain immutable unless a new versioned derivative is explicitly created.

## Mandatory reuse gate

Before any new:

- scientific gate;
- audit;
- experiment;
- domain selection;
- dataset search or feasibility assessment;
- operationalisation;
- cross-domain translation;
- technical implementation that depends on a scientific construct;

the investigator must consult this registry and follow every relevant prior artefact to its canonical or historical location.

A new operation may claim an independent/from-scratch starting point only when the prior-art review explicitly records why registered material is not applicable.

## Registry semantics

Each registered artefact must have, at minimum:

- stable identity;
- historical/current status;
- original location;
- canonical location or canonical pointer;
- scientific role;
- affected constructs/gates/domains;
- epistemic status;
- reuse relevance;
- obsolescence/supersession information where applicable.

The registry is a **governance control surface**, not an evidence-upgrade mechanism. Registration does not change scientific claims, evidence levels or gate status.

## Current bootstrap

The initial registry is being populated from the existing `TGCV_*` scientific artefacts in `02_LITERATURE/`, beginning with the artefacts identified during the September 2026 governance reconciliation.
