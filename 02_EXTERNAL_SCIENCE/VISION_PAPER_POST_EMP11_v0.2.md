# TGCV — Vision Paper v0.2 (Post-EMP-1.1)

**Status:** Strategic scientific draft — post-empirical update

## Abstract

Complex adaptive and generative systems can change not only their state, but the set of transformations available to them. A broad literature studies fragments of this phenomenon under different concepts, including adaptation, affordances, dynamic capabilities, self-* systems, runtime composition, learning and evolution. TGCV proposes a transversal analytical perspective centred on interactions that modify a system's accessible transformations.

The programme asks whether accessibility can be represented independently enough from conventional state descriptions to explain subsequent differences in system behaviour and, ultimately, contribute to an account of value creation. Its central relation is expressed as `S → T_acc = F(S,C,L) → ΔT_acc → ΔTrajectory → Value`.

A first confirmatory computational experiment, TGCV-EMP-1.1, produced positive evidence under a sealed operationalisation: mean test LogLoss improvement `+0.07942` against a predeclared `0.04` threshold, with paired sign-flip Monte-Carlo `p < 0.000005`. Controls indicated that the effect was not adequately explained by accessibility cardinality alone or by arbitrary permutation of relational accessibility structure. These results support the predictive usefulness of the tested accessibility representation, while leaving generality, causal interpretation, trajectory effects and value creation open to independent investigation.

## 1. The opportunity

The scientific landscape contains many mature theories of adaptation and change, yet the mechanisms by which interactions alter what a system can subsequently do remain conceptually fragmented. TGCV treats this modification of accessible transformations as a candidate transversal phenomenon rather than assuming that existing domain-specific constructs are equivalent.

## 2. The core proposition

For a system represented by state `S`, context `C` and constraints/resources `L`, the programme considers an accessibility function:

`T_acc = F(S,C,L)`.

The key object is not the current state alone, but the transformation set that is accessible from that state under its conditions. The research programme then investigates whether changes in that set can explain changes in subsequent trajectories and whether those changes can ultimately be related to value.

## 3. What has now been learned

EMP-1.1 changes the status of the programme. TGCV is no longer supported only by conceptual argument. The tested operationalisation produced a statistically strong predictive improvement and survived controls designed to distinguish relational accessibility information from simple count effects and arbitrary structure.

The result should nevertheless be interpreted narrowly: it is evidence for the specified computational operationalisation in the tested environment, not universal validation of TGCV.

## 4. The research programme beyond the first test

The next stage is independent replication and generalisation. It will examine:

- whether accessibility remains informative under an independently specified operationalisation;
- whether the effect transfers across empirical domains;
- which components of state, context and constraints are necessary;
- where the representation fails or adds no information;
- whether accessibility changes predict trajectory changes;
- under what conditions accessibility changes can be connected to practical value.

## 5. Scientific contribution sought

TGCV aims to develop a layered contribution:

1. a transversal conceptual account of accessibility-changing interactions;
2. an ontology and formal model where evidence warrants them;
3. an empirically testable reference architecture;
4. a reproducible methodology derived from validated principles;
5. empirical evidence and explicit boundary conditions;
6. pathways through which validated knowledge can generate practical impact.

## 6. A programme, not a single theory

TGCV is the first major theoretical result of a broader R&D programme. The programme is designed as a permanent knowledge-production capability rather than as a one-off theory project. Its governing flow is:

`Problem → Questions → Evidence → Knowledge → Theory → Design → Impact → Programme Learning`.

Documents, methods and governance mechanisms exist to stabilise this flow; they are not substitutes for it.

## 7. Falsifiability

The programme remains explicitly falsifiable. Null replication, negative cases, boundary conditions or evidence that conventional representations explain the phenomenon equally well are legitimate outcomes. The theory must evolve through evidence rather than through post-hoc accommodation of successful experiments.

## 8. Outlook

The immediate scientific objective is not to maximise the apparent scope of the first positive result. It is to determine how far the underlying phenomenon travels, where it fails, and which parts of the proposed theoretical chain survive independent scrutiny.

If that programme succeeds, TGCV could provide a common analytical layer for understanding how systems acquire, lose or reorganise future possibilities for transformation. If it fails at identifiable boundaries, those boundaries will themselves constitute scientific knowledge.
